### 2. Automated Backup Service
**Technologies:** `GitHub Actions` `Terraform` `Python` `Azure Native Backup` `AzCopy`

- Designed and implemented an automated backup solution for all the Azure resources based on native cloud services, built to be reusable across all environments. This solution significantly improved scalability, reduced delivery time, and requires
- minimal to no maintenance. Once configured, it automatically handles newly discovered or removed resources, ensuring scheduled backups are always maintained. Delivered backups for all the existing resources in our modern subscription within 9 months period and around 99% backup operation success rate because of the reliability of the solution.
- Developed a custom backup script to address scenarios not supported by Azure’s native backup capabilities. This script runs daily on our cluster to perform regular backups and is fully integrated into our standard GitOps workflow

---

### 3. Webhook Security Framework for Azure Automation
**Technologies:** `Azure Automation` `Python` `Runbooks` `Azure Key Vault`

- Identified and remediated a critical security gap in Azure Automation where publicly accessible webhook URLs could trigger runbooks without secondary authentication.
- Architected a custom authentication layer where unique tokens are generated at webhook creation and stored securely in Azure Key Vault.
- Developed a validation logic within runbooks to intercept the WebhookData payload, verifying the presence of a valid auth token in the request header before allowing script execution.
- Standardized organizational security posture by ensuring no runbook can be triggered by unauthorized or anonymous external calls.

---

### 4. Python Dispatcher for Azure Automation Hybrid Workers
**Technologies:** `Azure Automation` `Python` `Runbooks` `Virtual Environments`

- Developed a Python dispatcher module to dynamically load and execute runbooks in the virtual environment specified in the script shebang, enabling controlled runtime environments on Azure Automation Hybrid Worker VMs.
- Implemented a runtime shim layer that launches scripts in the designated virtualenv, overcoming Azure Automation’s default system Python limitation.
- Enabled local runbook execution within internal networks via Hybrid Worker VMs while maintaining strict control
over Python dependencies and environment isolation.
- Improved runbook reliability and dependency management by mapping runbooks to dedicated virtual environments
on hybrid worker infrastructure.
